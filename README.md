# Quackfinder

## Contributing

Make sure you have the repo on your local device:
```bash
git clone git@github.com:f0dn/quackfinder.git
cd quackfinder
```

If you haven't already made a branch, create one:
```bash
git checkout -b name-of-what-you-are-working-on
```

Then you can edit any code!
When you are done coding something commit it and push to github:
```bash
git add . # this means that you are going to commit all the changes you made
git commit -m "put a short but descriptive message of what you did"
git push --set-upstream origin branch-name
```

If you already pushed to the branch with `--set-upstream`, you can just do `git push`.

If it's your first time pushing to a new branch, create a pull request!

In the repository on github, a button should appear asking you to create a pull
request. Click it, explain what you are adding in the title and description, and
then create the pull request.
